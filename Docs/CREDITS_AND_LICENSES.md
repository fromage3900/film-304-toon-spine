# Credits and licences

Written 2026-09-30. For a college film submission, provenance is usually a rubric line, and
"where did this come from" is a question you want an answer to before someone else asks.

## This repository

| Item | Status |
|---|---|
| `MelodiaToonFilm` project (Content, Config, Python, Blender, Tools, Docs) | Original work, Animation Art 5 group project, Humber College |
| `Content/Materials/**` | Generated by the Python builders in this repo — no third-party asset content |
| `Blender/surreal_arch/**` | Vendored from the Melodia project — original work by the same author |
| `MelodiaToonFilm.uproject` | Content-only; no C++ module |

There is currently **no `LICENSE` file** in this repo. That is fine for a private course
submission and a mistake for anything public or reused: without a licence, nobody else may legally
use it. Decide deliberately:

- keep it private / submission-only → add nothing, but do add a one-line "all rights reserved"
  note to this file;
- want it reusable → add `LICENSE` (MIT is the usual choice for tooling) and reference it here.

## Third-party content actually in the repo

**None.** That is worth stating plainly, because it is easy to lose:

- the **Higgsas geometry-node library** is referenced by the builders (`higgsas_pipeline.py`) but
  is **not vendored** — it is machine-local, gitignored, and licensed separately. Where it is
  absent the builders take a documented native fallback, which is why every check passes on a
  clean clone. **Do not commit it**, and do not ship a `.blend` that depends on it being present
  on the reviewer's machine.
- **Quixel Megascans** is mentioned in `Docs/FILM_PIPELINE.md` as a production option. Nothing
  from it is in this repo. If you add Megascans content, note it here and check the licence for
  the Epic-plan you are on.
- **`2kmTemplate`** is referenced by `L_Toon_Lookdev.umap` but is not in this repo. It is a
  throwaway template level, not a licensed asset — see `Docs/AUDIT_2026-09-30.md`.
